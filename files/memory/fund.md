# The fund this pod runs for

Not set yet. The fund's identity lives in the `thesis` row — fund name, website, stages,
geographies, sectors, cheque size — which the app's first run fills from the fund's website.
That row is the single source the evaluator scores against and the app renders; never hardcode
the fund name in an app or an agent.

Use this file for what the thesis row cannot hold: how the partnership likes deals presented,
names the fund goes by, relationships worth knowing. Keep it short, and cite where each fact
came from.

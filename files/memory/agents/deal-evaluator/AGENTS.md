# deal-evaluator — shared state (pod-wide)

Index. One line per topic; detail lives in the file.

- `scoring.md` — how the five scores and `score_overall` are derived, and how thesis deal-breakers become flags.
- `verification.md` — how to treat relayed/second-hand claims, an announced-but-absent artefact, and what a failed verification does to a score.
- `founder-name-arrivals.md` — the founder-name intake defect: check for a sibling card, re-read the deal row before writing, never borrow a sibling's facts; what to do when the sibling card is gone; no company means no profile lookup.
- `deals/` — per-deal verified findings kept for re-scores, one file per deal.
